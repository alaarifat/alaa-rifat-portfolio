# Alaa Rifat — bilingual portfolio

A static, responsive Arabic/English portfolio website.

## Included
- Arabic RTL and English LTR with a language switch
- Cairo font files bundled locally (from the supplied Cairo archive)
- White, black and purple identity: #FFFFFF, #111111, #504471
- Responsive layout, no external libraries or paid services
- Contact links and links to Refaah Group and published work

## Preview locally
Open `index.html` in a browser.

## Free publishing with GitHub Pages
1. Create a GitHub account and a new public repository (for example `alaa-refaat-portfolio`).
2. Upload all files and folders in this package, preserving the folder structure.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. GitHub will provide a free `github.io` address. A custom domain can be connected later; domain registration is the only expected cost.

## Before publishing
- Review every date, institutional title and project name.
- Add approved portrait photography if desired; no portrait was fabricated or added.
- Add direct links to the media coverage and story publications if you have their exact URLs.
- The English text is a professional localisation of the supplied portfolio, not a certified translation.
